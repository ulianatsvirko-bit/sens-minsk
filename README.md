# СЭНС — культурное пространство в Минске

Сайт СЭНС: знакомство с пространством и труппой, афиша мероприятий, информация об аренде и формы записи. Администратор может создавать и публиковать события, редактировать расписание и загружать фотографии.

## Технологии

- HTML, CSS и JavaScript без фронтенд-фреймворка и этапа сборки.
- Node.js, Express, SQLite (`better-sqlite3`).
- Multer для загрузки изображений, Helmet для HTTP-заголовков.
- Функции Vercel для отправки заявок в Telegram.

## Локальный запуск

Требуются Node.js 20 или новее и npm.

```bash
git clone https://github.com/ulianatsvirko-bit/sens-minsk.git
cd sens-minsk
npm ci
cp .env.example .env
```

Отредактируйте `.env`: задайте `ADMIN_LOGIN`, собственный `ADMIN_PASSWORD` и `SESSION_SECRET` длиной не менее 32 символов. Для локальной разработки установите `NODE_ENV=development`. Секрет можно сгенерировать командой `openssl rand -hex 32`.

Сервер не загружает `.env` автоматически. В bash или zsh экспортируйте переменные перед запуском:

```bash
set -a
source .env
set +a
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). Команда `npm run dev` перезапускает сервер при изменениях; `npm start` запускает его без наблюдения за файлами.

При первом запуске автоматически создаются пустая база `data/events.sqlite` и папка `uploads/`. Добавьте события через [админ-панель](http://localhost:3000/admin.html), используя логин и пароль из `.env`. В публичную афишу попадают только опубликованные события.

## Страницы

| Адрес | Содержимое |
| --- | --- |
| `/` | Главная страница: афиша, зал, спектакли, коротко о труппе |
| `/troupe.html` | Вся труппа |
| `/artist.html?id=…` | Личная страница артиста: кто он и фотографии (данные в `lib/troupe.js`) |
| `/events.html` | Афиша и фильтры мероприятий |
| `/event.html?id=…` | Подробности события и запись |
| `/space.html` | Пространство |
| `/rent.html` | Аренда и сотрудничество |
| `/admin.html` | Управление событиями |

## Настройки окружения

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт Express, по умолчанию `3000` |
| `NODE_ENV` | Режим окружения: `development` или `production` |
| `ADMIN_LOGIN` | Обязательный логин администратора |
| `ADMIN_PASSWORD` | Обязательный пароль администратора |
| `SESSION_SECRET` | Обязательное значение длиной от 32 символов, проверяемое при запуске |
| `TELEGRAM_BOT_TOKEN` | Токен бота для функций отправки заявок на Vercel |
| `TELEGRAM_CHAT_ID` | Получатель заявок в Telegram |

`.env`, `node_modules/`, `data/` и `uploads/` исключены из Git. Не добавляйте пароли и токены в репозиторий.

## Развёртывание и формы

Текущая конфигурация разделяет сайт между Vercel и VPS:

- Vercel отдаёт страницы и выполняет `api/contact.js` и `api/register.js`. Эти функции отправляют заявки в Telegram; для них нужно задать обе переменные `TELEGRAM_*` в окружении Vercel.
- Express на VPS хранит события в SQLite, обслуживает авторизацию, админ-панель и загруженные изображения. Правила в `vercel.json` перенаправляют соответствующие запросы на VPS.

Обычный запуск `npm start` обслуживает страницы и API событий, но **не подключает обработчики `/api/contact` и `/api/register`**. Для работы отправки форм нужна среда Vercel либо отдельное подключение этих обработчиков к серверу.

Адрес API сервера указан в `vercel.json` и `api/register.js`, а разрешённые домены прокси — в `server.js`. При переносе на другой домен или сервер обновите эти значения.

Подробная инструкция для VPS, Nginx, HTTPS и PM2: [DEPLOY-VPS.md](DEPLOY-VPS.md).

Для резервного копирования сохраняйте базу SQLite из `data/` и изображения из `uploads/`. Они не восстанавливаются клонированием репозитория. Сессии администратора хранятся в памяти: после перезапуска сервера потребуется войти снова.

## Структура проекта

```text
assets/          Фотографии, шрифты и графика
api/             Функции Vercel для заявок
lib/             Общая логика событий и расписания
test/            Тесты на встроенном тестовом раннере Node.js
output/          Подготовленные материалы и документы
server.js        Express, SQLite, авторизация и загрузка изображений
*.html           Страницы сайта
*.css, *.js      Стили и браузерная логика
vercel.json      Проксирование API и маршрутизация Vercel
```
