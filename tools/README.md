# Инструменты генерации

Скрипты в этой папке создают экспортированные материалы в `output/` и не участвуют в работе сайта.

- `create_carousel.py` — создаёт Instagram-карусель;
- `create_event_stories.py` — создаёт вертикальные stories;
- `export_carousel_png.mjs` — экспортирует HTML-карусель в PNG через Playwright.
