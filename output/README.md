# Готовые материалы

В этой папке хранятся экспортированные материалы, которые не нужны для запуска сайта:

- `carousel/` — изображения Instagram-карусели;
- `event-stories/` — вертикальные stories;
- `pdf/` — пресс- и технические материалы;
- `*.zip` — архивы для передачи;
- `*.docx` — редактируемые документы.

Рабочие скрипты генерации находятся в [`../tools/`](../tools/).
